To connect a domain purchased on GoDaddy to your GitHub Pages website, you need to configure your DNS settings inside your GoDaddy account and register the domain inside your GitHub repository.

Step 1: Add the Custom Domain in GitHub

1. Log in to GitHub and navigate to the repository hosting your website.
2. Click Settings in the top navigation bar.
3. In the left sidebar, click Pages.
4. Under the Custom domain section, enter your domain name (e.g., yourdomain.com) and click Save. (This automatically generates a CNAME file in the root of your repository).

Step 2: Configure DNS Records in GoDaddy

1. Log in to your account on GoDaddy and go to My Products > Domains.
2. Find the domain you want to use, click the three dots (or Manage) next to it, and select Manage DNS (or DNS Zone File).
3. Delete any conflicting default or parking records (such as preexisting default A records or GoDaddy website builder CNAMEs that might block GitHub).
4. Add the four A Records (for your apex/naked domain, e.g., yourdomain.com) by clicking Add New Record:
	• Type: A
	• Name / Host: @
	• Value / Points to: 185.199.108.153 (Repeat to add the other three official GitHub IPs below)
		• 185.199.109.153
		• 185.199.110.153
		• 185.199.111.153
5. Add the CNAME Record (for the www subdomain):
	• Type: CNAME
	• Name / Host: www
	• Value / Points to: yourusername.github.io (replace with your actual GitHub username)
	• TTL: Set to 1 Hour (or default)

Step 3: Verify and Enable HTTPS

1. Go back to your repository Settings > Pages on GitHub.
2. Wait a few minutes (propagation can occasionally take up to 24 hours, though it is usually faster) until the DNS check turns green.
3. Once verified, check the box for Enforce HTTPS to generate and activate your free SSL certificate.
